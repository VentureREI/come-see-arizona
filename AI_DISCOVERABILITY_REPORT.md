## Phase 0 — Stack Map (Architect)

### Framework & render mode
- **Build tool:** Vite 7, React 19, TypeScript ~5.9.
- **Routing:** React Router 7 (`BrowserRouter`, client-side) in `src/Router.tsx`; a parallel `StaticRouter` route table in `src/entry-server.tsx` for SSR string rendering.
- **Render mode:** **SSG / prerendered**. `scripts/prerender.ts` spins up a Vite SSR server, calls `render(url)` from `entry-server.tsx` (`renderToString`), and writes a static `dist/<route>/index.html` for every route (~460). Client hydrates after load. Bots therefore receive **full HTML**, not a JS shell (confirmed in `dist/things-to-do/index.html` — real `#root` content + JSON-LD present).
- **Head management:** `react-helmet-async` via `src/components/seo/SEOHead.tsx`. `entry-server.tsx` regex-extracts Helmet `<title>/<meta>/<link rel=canonical>/<script ld+json>` from the rendered markup and injects into `<head>`; `prerender.ts` strips the template's placeholder title/OG/canonical tags first so per-page tags win.

### Content source
- **Static TS datasets:** `src/data/` — `cities.ts`, `counties.ts`, `neighborhoods.ts`, `zipCodes.ts`, `schoolDistricts.ts`, `trails.ts`, `trailsSouthernNorthern.ts`, `thingsToDo.ts`, `events.ts`, etc.
- **Dynamic JSON:** `src/data/dynamic/` — `events.json`, `featuredContent.json`, `marketPrices.json`, `trailConditions.json` (loaded via `dynamicLoader.ts`); refreshed by the autonomous engine described in `siteConfig.ts`.

### Hosting & delivery
- **Vercel.** `vercel.json`: caches `/assets/*` immutable, `*.html` no-cache, everything else `s-maxage=86400`; SPA rewrite `/(.*) → /index.html`. (Vercel filesystem match precedes rewrites, so prerendered `/<route>/index.html` is served for clean URLs — to be confirmed by Crawlability/Verification.)

### Existing discoverability infrastructure (baseline)
- `public/robots.txt` — explicitly **Allows** GPTBot, ChatGPT-User, Google-Extended, ClaudeBot, PerplexityBot, Bytespider, Applebot-Extended, cohere-ai, plus `User-agent: *`. Points to sitemap + llms.txt.
- `public/sitemap.xml` — ~84 KB, generated by `scripts/generate-sitemap.ts`.
- `public/llms.txt` — detailed AI-crawler guide (authority map, citation guidance, data sources, update cadence).
- `scripts/ping-indexnow.ts`, `public/indexnow-key.txt` — IndexNow submission.
- `scripts/validate-build.ts` — build validation.
- `SEOHead.tsx` (Organization/WebSite/Breadcrumb/per-page schema), `AnswerBlock.tsx` (AEO answer-first block), shadcn `breadcrumb` UI.

### Architect's pre-dispatch findings (handed to agents)
1. **NAP/canonical host mismatch:** `siteConfig.siteUrl = 'https://www.comeseearizona.com'` (www) vs. `SEOHead`, `robots.txt`, `sitemap.xml`, `llms.txt` all use the **non-www apex** `https://comeseearizona.com`. One canonical host must be chosen sitewide. (Crawlability + GEO)
2. **Possible missing canonical on some prerendered subpages** (`/things-to-do` showed no `<link rel=canonical>` in dist while `/` did). (Crawlability + On-Page)
3. **Duplicate `description` meta** observed in `dist/things-to-do/index.html`. (On-Page + Verification)
4. `SEOHead.tsx` hardcodes `siteUrl` instead of importing `siteConfig` — duplication risk. (GEO/On-Page)
